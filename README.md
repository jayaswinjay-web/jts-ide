## What is this?

JTS IDE is a **lightweight, dark-themed editor** built for people learning the [JTS GO programming language](https://github.com/jayaswinjay-web/jtsdk). It comes bundled with the language so a beginner can go from **zero to running their first program in under a minute** — no toolchain setup, no environment variables, no configuration.

Press **F5** to run your code. That's the whole idea.

---

## Features

- **Syntax highlighting** for `.jts` files out of the box
- **Run with F5** — the program's output streams into an embedded console
- **Build bytecode with F6** — compile `.jts` to `.jbc` and inspect results
- **Interactive REPL** — type JTS GO code live and see results instantly
- **Multi-file tabs** — Ctrl+N / Ctrl+O / Ctrl+S, just like you expect
- **Open Folder workspace** — work on whole projects, not just single files
- **Error list** — compile errors with file, line, and message, double-click to jump
- **Built-in tutorials** — beginners get guided examples without leaving the app
- **Native dark theme** — easy on the eyes, native Windows title bar

---

## Quick Start

The simplest path: install the [JTS Development Kit](https://github.com/jayaswinjay-web/jtsdk) — the IDE ships inside the installer, already wired to the language.

> The IDE targets **.NET Framework 4.8**, so it runs on Windows 7 and up.
